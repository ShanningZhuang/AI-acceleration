## Course Overview

This course aims to build a full-stack knowledge system for AI acceleration, covering seven levels: mathematics, algorithms, pruning, quantization, sparsity, architecture, and chip design.

The course covers the following topics:
- **Mathematics**: Fundamental DNN and CNN network architectures and training methods.
- **Algorithms**: Exploration of various network architectures like AlexNet, VGG, ResNet, and Inception, along with analysis of different layers such as Batch Normalization and Pooling.
- **Pruning**: Discussion of structured and non-structured pruning methods, including an introduction to the ADMM algorithm.
- **Quantization**: Introduction to 8-bit, 4-bit, 3-value, and 2-value networks, along with related training methods and challenges.
- **Sparsity**: Exploration of hardware-software co-design for sparsity.
- **Chip Architecture**: Examination of memory wall issues, systolic arrays, and other architectures.
- **Chip Design**: Fundamentals of dynamic design with DRAM and SRAM, and an introduction to Processing-In-Memory (PIM).
